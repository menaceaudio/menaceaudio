# Menace Audio — Trap Vocal Chain (VST3)

Gain → HPF → Tame → Gate → De-Ess → Comp → Warmth → AIR → Delay (sync) → Reverb → Width → Mix → Out

| Seção    | Knobs |
|----------|-------|
| Input    | Gain, HPF, Tame (doma a presença do condensador), Gate |
| Dynamics | De-Ess, Comp, Speed, Warmth |
| Air      | Air (shelf), Freq, Drive (harmônicos), Spark (octave-up) |
| Delay    | Mix, Time (1/4, 1/4 D, 1/8, 1/8 D, 1/16, 1/8 T), Feedback, Dark |
| Reverb   | Mix, Size, Pre (pre-delay), Damp |
| Master   | Width, Mix (dry/wet), Out |

Presets: Init, Utopia, Toliver Silk, Dark Throw, Clean Booth, Air Maluco.

Os knobs têm travas: cada pontinho é uma posição. Clique duplo volta ao padrão.

## Instalar

Build automático no GitHub (aba Actions) gera o `MenaceAudio-Setup.exe`.
Depois: FL Studio → Options → Manage plugins → Find installed plugins.
